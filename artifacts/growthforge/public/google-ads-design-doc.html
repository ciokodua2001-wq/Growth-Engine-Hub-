GrowthForge AI – Google Ads API Design Documentation

Company: Strapli Technologies Inc.  |  Product: GrowthForge AI (usegrowthforge.com)  |  Date: July 2026

1. Tool Overview

GrowthForge AI is an AI-powered marketing SaaS platform that serves as a complete AI marketing department for small and medium-sized businesses. Users connect their Google Ads account to the platform via OAuth 2.0 to import real campaign performance data, view AI-generated optimization recommendations, and monitor all campaigns in one unified dashboard.

2. Google Ads API Feature: Campaign Manager

Feature name: Campaign Manager – Google Ads Sync

Location: Project Dashboard › Campaign Manager

User flow:

  • User navigates to Campaign Manager inside their GrowthForge project.
  • A "Connect Google Ads" panel is displayed at the top of the page.
  • User clicks "Connect Google Ads" — initiates OAuth 2.0 consent flow with scope adwords.
  • User grants permission on Google's OAuth consent screen.
  • Platform stores the refresh token server-side; user is redirected back to Campaign Manager.
  • User sees their connected account info (email, customer ID, last sync time).
  • User clicks "Sync Now" — platform fetches the latest campaign data via Google Ads API GAQL query (last 30 days).
  • Campaigns appear in the dashboard with real metrics: impressions, clicks, conversions, spend, CTR, CPC, ROAS.
  • Synced campaigns are visually badged as "Google Ads" for clear attribution.

3. Campaign Types Supported

Search, Display, Video, Performance Max

Campaign type is read from campaign.advertising_channel_type in the API response and displayed alongside each campaign row.

4. Capabilities Provided

  • Campaign Management: Users can view, monitor, and track all active Google Ads campaigns from within GrowthForge.
  • Reporting: Platform surfaces 30-day performance summaries (impressions, clicks, conversions, spend, ROAS, CTR, CPC) and AI-generated recommendations based on real campaign data.

5. GAQL Query Used

SELECT campaign.id, campaign.name, campaign.status, campaign.advertising_channel_type, metrics.impressions, metrics.clicks, metrics.conversions, metrics.cost_micros, metrics.ctr, metrics.average_cpc FROM campaign WHERE segments.date DURING LAST_30_DAYS AND campaign.status != 'REMOVED' ORDER BY metrics.impressions DESC LIMIT 50

6. OAuth & API Access Details

  • OAuth scope: https://www.googleapis.com/auth/adwords
  • Auth type: OAuth 2.0 with offline access (refresh token)
  • Redirect URI: https://usegrowthforge.com/api/auth/google-ads/callback
  • API version: Google Ads API v18
  • Login-customer-id: Manager account customer ID passed in header for agency flows

7. Data Storage & Security

  • OAuth tokens stored server-side in a PostgreSQL database — never exposed to the browser.
  • Access tokens refreshed automatically on expiry using the stored refresh token.
  • Campaign data cached in the platform database and refreshed on user request ("Sync Now").
  • Users can disconnect their Google Ads account at any time — tokens are immediately deleted and synced campaigns revert to manual entries.
  • All API communication happens server-to-server; the developer token is never sent to the client.

8. Who Has Access

External users — GrowthForge customers access this feature through their own authenticated GrowthForge account. Each user connects their own Google Ads account via OAuth. The platform never accesses any Google Ads account without explicit authorization from the account owner.

9. Target Audience

  • Small and medium-sized businesses running Google Ads campaigns who want a unified AI marketing dashboard.
  • Marketing agencies managing Google Ads on behalf of multiple clients.
